## 🚀 Skills Disponibles

### 1. `crear-web`
Skill inteligente para inicializar proyectos web en **Next.js (última versión)** con los más altos estándares de calidad, UI y arquitectura:
- **Interacción y Control**: Pregunta siempre al usuario el nombre del proyecto antes de ejecutar cualquier comando.
- **Framework**: Next.js (App Router, TypeScript, ESLint, `src/`).
- **Librerías de UI y Animación**: `lucide-react`, `simple-icons`, `motion`.
- **Skills integrados**: 
  - `vercel-react-best-practices` (Optimización y performance de Vercel).
  - `frontend-design` (Directrices de diseño visual distintivo de Anthropic).
- **Directrices Corporativas**: Paleta oficial de GearSoftCA (`#131D47`, `#9AECED`, `#4C4C4C`, `#F1F1F1`).

---

## 📦 Cómo Usar Este Skill en Cualquier Proyecto o Máquina

Puedes instalar este skill directamente en cualquier proyecto con herramientas compatibles (Cursor, Antigravity IDE, Claude Code, Gemini CLI, Copilot):

```bash
npx skills add https://github.com/JavierAlburges/gearsoftca-skills --skill crear-web
```

Para instalarlo **globalmente** en tu máquina (disponible para todos los proyectos):

```bash
npx skills add https://github.com/JavierAlburges/gearsoftca-skills --skill crear-web -g
```

---

## 🛠️ Scripts de Terminal (Windows)

Si prefieres ejecutar el asistente directamente sin abrir el chat de la IA, dispones de dos opciones en la carpeta `scripts/`:

1. **PowerShell (`crear-web.ps1`)**:
   ```powershell
   .\scripts\crear-web.ps1
   ```
2. **Doble Clic (`crear-web.bat`)**:
   - Haz doble clic en el archivo `crear-web.bat` desde el explorador de archivos de Windows. Te pedirá el nombre del proyecto en una consola interactiva.
